RM Creator Tools

RM Creator Tools is a private, internal tool used by the owner to manage his own YouTube channels, including It's a Musical Now.

It uses the YouTube Data API and YouTube Analytics API to:

  • upload and schedule videos and set thumbnails on the owner's channels;
  • read comments and post replies approved by the owner;
  • read channel and video analytics for the owner's own reporting.

The tool is not offered to the public. It only accesses channels owned or managed by the owner.
